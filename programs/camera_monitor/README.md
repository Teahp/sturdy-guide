# 并发摄像头监视器


## 功能

- 支持选择摄像头设备和分辨率
- 后台线程持续采集图像
- 主线程显示最新图像
- 显示帧编号和 FPS
- 按 `S` 保存截图
- 按 `Q` 或关闭窗口退出
- 缓冲区最多保存两帧
- 后台异常可传递到主线程
- 使用假摄像头完成自动化测试
